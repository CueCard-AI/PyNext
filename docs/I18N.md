# PyNext Internationalization (i18n)

> Signal-Based Locale with Direct DOM Updates (No Re-renders)

## Overview

PyNext i18n applies SolidJS principles:

| Feature | Next.js | PyNext |
|---------|---------|--------|
| **Locale Change** | Full re-render | **Text nodes only** |
| **Loading** | Bundle all locales | **Lazy per-locale** |
| **Updates** | Component re-render | **Direct DOM update** |
| **Detection** | Runtime | **Build-time variants** |

## Quick Start

```python
from pynext import t, set_locale

# Translate a key
h1(t("welcome"))  # "Welcome" or "Bienvenue"

# Switch locale (only text updates, no re-render!)
set_locale("fr")
```

## Configuration

```python
from pynext import LocaleConfig, configure_i18n

configure_i18n(LocaleConfig(
    locales=["en", "fr", "de", "es"],
    default_locale="en",
    fallback_locale="en",
    locale_detection=True,
    strategy="prefix",  # /en/about, /fr/about
    translations_path="locales",
))
```

## Translation Function

### Basic Translation

```python
from pynext import t

# Simple key
t("welcome")  # "Welcome"

# With parameters
t("greeting", {"name": "Alice"})  # "Hello, Alice!"

# With default fallback
t("unknown_key", default="Fallback text")
```

### Nested Keys

```json
{
  "nav": {
    "home": "Home",
    "about": "About",
    "contact": "Contact"
  }
}
```

```python
t("nav.home")     # "Home"
t("nav.about")    # "About"
```

### Pluralization

```json
{
  "items": {
    "zero": "No items",
    "one": "1 item",
    "other": "{count} items"
  }
}
```

```python
from pynext.i18n import t

# t() doesn't handle plurals directly
# Use the count in params
t("items.other", {"count": 5})  # "5 items"
```

## Reactive Translation Element

For text that updates when locale changes:

```python
from pynext.i18n.locale import t_element

# Creates element with data-i18n attribute
t_element("welcome")
# <span data-i18n="welcome">Welcome</span>

# With parameters
t_element("greeting", {"name": "Alice"})
# <span data-i18n="greeting" data-i18n-params='{"name":"Alice"}'>Hello, Alice!</span>
```

When locale changes, only these elements update!

## Locale Signal

Access the reactive locale:

```python
from pynext import use_locale, get_locale, set_locale

# Get current locale
current = get_locale()  # "en"

# Set locale
set_locale("fr")

# Reactive access
locale = use_locale()
locale.get()        # "en"
locale.set("fr")    # Triggers updates
```

## Locale Provider

Wrap content with locale context:

```python
from pynext import LocaleProvider

def app():
    return LocaleProvider("en",
        div(
            h1(t("welcome")),
            p(t("description")),
        )
    )
```

## Formatting Functions

### Numbers

```python
from pynext import format_number

format_number(1234567.89)  # "1,234,567.89"
format_number(0.75, style="percent")  # "75%"
```

### Dates

```python
from pynext import format_date
from datetime import datetime

now = datetime.now()

format_date(now)                    # "Nov 25, 2024"
format_date(now, format="short")    # "11/25/24"
format_date(now, format="long")     # "November 25, 2024"
format_date(now, format="full")     # "Monday, November 25, 2024"
```

### Currency

```python

format_currency(99.99, "USD")  # "$99.99"
format_currency(99.99, "EUR")  # "€99.99"

```

### Relative Time

```python
from pynext.i18n import format_relative_time
from datetime import datetime, timedelta

past = datetime.now() - timedelta(hours=2)
format_relative_time(past)  # "2 hours ago"

past = datetime.now() - timedelta(days=3)
format_relative_time(past)  # "3 days ago"
```

## Lazy Loading

Translations load on-demand:

```python
from pynext.i18n import load_translations

# Load synchronously
load_translations("fr", namespace="common")

# Load asynchronously (for lazy loading)
await load_translations_async("fr", namespace="products")
```

Client-side lazy loading:
```javascript
// Only loads when locale changes
await __pynext__.i18n.setLocale("fr");
// Fetches /locales/fr/common.json
```

## Direct DOM Updates

When locale changes, PyNext updates text directly:

```
Locale Change: en → fr
        │
        ├──▶ Find [data-i18n] elements
        │
        ├──▶ Get new translations
        │
        └──▶ Update textContent directly
             (No component re-render!)
```

```javascript
// Client-side implementation
document.querySelectorAll('[data-i18n]').forEach(el => {
    const key = el.dataset.i18n;
    el.textContent = t(key);  // Direct update!
});
```

## Middleware for Locale Detection

```python
from pynext.i18n import add_locale_middleware

# Add to FastAPI app
add_locale_middleware(app, config=LocaleConfig(
    locales=["en", "fr", "de"],
    default_locale="en",
))
```

Detection priority:
1. URL prefix (`/fr/about`)
2. Cookie (`PYNEXT_LOCALE`)
3. Accept-Language header
4. Default locale

## URL Strategies

### Prefix Strategy

```
/en/about  → English
/fr/about  → French
/de/about  → German
```

### Domain Strategy

```
example.com    → English
fr.example.com → French
de.example.com → German
```

## Build-Time Extraction

Extract translation keys from source:

```python
from pynext.i18n.extractor import TranslationExtractor

# Extract all t() calls
extractor = TranslationExtractor(Path("pages"))
result = extractor.extract()

print(result.get_unique_keys())
# {"welcome", "greeting", "nav.home", ...}
```

Validate translations:
```python
from pynext.i18n.extractor import TranslationValidator

validator = TranslationValidator(
    Path("locales"),
    locales=["en", "fr", "de"],
)

result = validator.validate(extracted)
# {
#   "locales": {
#     "en": {"missing": [], "coverage": 100},
#     "fr": {"missing": ["nav.contact"], "coverage": 95},
#   }
# }
```

## Client-Side API

```javascript
// Get current locale
__pynext__.i18n.locale  // "en"

// Set locale (updates DOM automatically)
await __pynext__.i18n.setLocale("fr")

// Translate
__pynext__.i18n.t("welcome")  // "Bienvenue"
__pynext__.i18n.t("greeting", {name: "Alice"})

// Subscribe to changes
const unsubscribe = __pynext__.i18n.subscribe((newLocale) => {
    console.log(`Locale changed to ${newLocale}`);
});

// Global shortcuts
t("welcome")        // Same as __pynext__.i18n.t()
setLocale("fr")     // Same as __pynext__.i18n.setLocale()
```

## Performance

| Operation | Next.js | PyNext |
|-----------|---------|--------|
| Initial Load | All locales | **Active only** |
| Locale Switch | Full re-render | **Text nodes only** |
| DOM Updates | Virtual DOM diff | **Direct textContent** |
| Bundle Size | All translations | **Lazy chunks** |

## Best Practices

1. **Use t_element for dynamic content** - Enables auto-update
2. **Namespace translations** - common.json, products.json
3. **Use fallback locale** - Graceful degradation
4. **Lazy load large locales** - Reduce initial bundle
5. **Extract and validate** - Catch missing translations
